# Keyboard shortcuts

The full list is in **Help → Keyboard Shortcuts**, labelled for your keyboard (QWERTY, AZERTY or QWERTZ, detected or set in Settings): letter shortcuts follow the letter, digit and symbol ones the key's position. Click any shortcut there and press new keys to change it (a key already in use moves over, and the window says from which command); changes are kept in `settings.json`.

The defaults, with QWERTY names:

## Paint

| Key | Action |
|---|---|
| Left drag | Paint (pen pressure where supported) |
| `B` / `E` | Brush / eraser |
| `[` / `]` | Brush size |
| `K` (hold), right-click | Pop-up brush palette |
| `S` | Smudge / blur |
| `I` | Eyedropper |
| `G` | Fill (again: enclose, lasso delete) |
| `Shift+G` | Gradient |
| `U` | Shapes |
| `R` | Ruler |

## View

| Key | Action |
|---|---|
| `Space` + drag, right drag | Pan |
| Middle drag | Rotate |
| Wheel | Zoom |
| `Ctrl+0` / `Ctrl+1` | Fit / actual pixels |
| `H` | Flip |
| `Shift+H` | Check view on / off (grey, values or saturation) |
| `Ctrl+'` / `Ctrl+;` | Grid / guides |
| `Tab` | Hide or show the panels |

## Tools

| Key | Action |
|---|---|
| `M` | Rectangle / ellipse select |
| `L` | Lasso (again: polygon, magnetic) |
| `Q` / `Shift+Q` | Magic wand / quick mask |
| `V`, `T` | Transform |
| `W` / `Shift+W` | Liquify / puppet warp |
| `Y` | Bones |
| `Shift+P` | Pen (paths) |

## Edit

| Key | Action |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z`, `Ctrl+Y` | Redo |
| `Ctrl+H` | History |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | Cut / copy / paste (as a new layer) |
| `Ctrl+Shift+C` | Copy merged |
| `Ctrl+J` | Duplicate layer |
| `Ctrl+Alt+G` | Clipping mask |
| `Ctrl+Alt+E` / `Ctrl+Shift+E` | Merge down / merge visible |
| `Ctrl+A` / `Ctrl+D`, `Esc` | Select all / deselect |
| `Ctrl+Shift+I` | Invert selection |
| `Delete` | Erase the selected pixels |
| `Shift+F5` | Content-aware fill |
| `Enter` / `Esc` | Apply / cancel a transform |

## File

| Key | Action |
|---|---|
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` | New / open / save |
| `Ctrl+E` | Export |
| `Ctrl+Shift+O` | Import an image as a layer |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Next / previous tab |
| `Ctrl+W` | Close tab |

## Animation

| Key | Action |
|---|---|
| `Shift+Space` | Play |
| `,` / `.` | Previous / next frame |
