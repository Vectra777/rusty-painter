# Filters

Every filter previews live on the layer or the selection; sliders preview smoothly even on a whole 4K canvas. The colour adjustments are also available as [adjustment layers](layers.md#adjustment-layers), and the blur tool's Filter mode paints any filter through the brush.

| Kind | Filters |
|---|---|
| Colour | Brightness/contrast, hue/saturation, levels, curves (a master curve and one per channel), colour balance (shadows, midtones, highlights), gradient map (any colours, with presets), invert, desaturate, posterize, threshold, exposure, temperature/tint, vibrance, sepia, solarize |
| Blur and sharpen | Gaussian, motion, zoom and spin blur, sharpen, reduce noise (median) |
| Effects | Glow, chromatic aberration, halftone, emboss, find edges, oil paint, vignette, noise, pixelate, dither, clouds |
| Line art | Extract Line Art: a scanned drawing's paper turns transparent |

## Gradients

`Shift+G`: linear, radial, reflected and angle gradients, previewed live, dithered, clipped to the selection.
